# PaisaTrack – Smart Expense Tracker

PaisaTrack is a **full-stack web-based financial management system** designed to help users efficiently track, analyze, and manage their financial activities. The system integrates **AI-powered automation**, secure authentication, and real-time analytics to provide a seamless user experience.

---

## Project Overview

Managing personal finances can be challenging without proper tools. PaisaTrack solves this problem by offering:

- Centralized expense and income tracking  
- Intelligent automation using AI  
- Secure and modern authentication systems  
- Real-time financial insights with visual dashboards  

This project was developed as a **Final Year Project (FYP)**, combining concepts from **AI, Web Development, and Database Systems**.

---

## Key Features

###  Authentication & Security
- User registration with **email verification**
- Secure login system using **JWT (JSON Web Tokens)**
- **Google OAuth Login/Signup** integration
- Password hashing using **bcrypt**
- Protected routes and role-based access

---

###  Financial Management
- Add, edit, and delete **income & expenses**
- Categorization of transactions
- Advanced **transaction filtering** (date, type, category)
- Support for **recurring transactions**
- Budget creation and tracking

---

###  AI-Powered Features
- **AI Receipt Scanner**  
  Extracts data (amount, date, items) from uploaded receipts  
- **AI Chatbot Assistant**  
  Helps users with:
  - Expense summaries  
  - Financial advice  
  - Smart queries  

---

### Data Visualization & Insights
- Interactive dashboard with:
  - Expense vs Income charts  
  - Category-wise breakdown  
- Budget alerts when spending exceeds limits  

---

###  Reports & Export
- Download reports in:
  - CSV format  
- Clean and structured financial reports  

---

### User Experience
- Responsive and user-friendly UI  
- Smooth navigation and minimal design  
- Built with accessibility and usability principles
